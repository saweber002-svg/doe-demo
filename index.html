Example Model — Reference Implementation Demo

Dungeons of Eternity Damage Companion

Dungeons of Eternity now floats damage points and multipliers up off enemies as you hit them (a display you can toggle in the game's settings). Every one of those rising numbers is built from the same recipe: a base hit, a roll of four perks, and where the hit landed. This companion teaches you to read those floating numbers at a glance — how often each outcome happens, what it pays, and what a big (or small) number actually means.

What this page is: an unofficial, fan-made example model built to hand to a development team — a reference implementation they can run, read, and lift into a production build. It is not the finished production app, and it is not affiliated with or endorsed by Othergate, the developer of Dungeons of Eternity. The damage maths and probability model below are real and verified against the example data in §08; the presentation is a demo shell showing how the model should surface to players. §08 is the technical spec, §09 the installation & handoff guide, and §10 the open questions the dev team must verify against the live game.
Built for how VR is actually played: this companion lives outside the headset — a phone or tablet second screen used before a run and between dungeons for loadout planning, never during combat. That drives the design: large touch targets, at-a-glance tables, a dark-theme-friendly palette, and nothing that needs fast interaction while you're in the dungeon.
The one formula behind every hit
FINAL DAMAGE = BASE × HITBOX × ( 1 + PROCCED PERK BONUSES )

Perks that don't proc add nothing. Perks that do proc add their bonus together first, then the hitbox multiplies the whole thing — which is why a stacked roll on the head pays half again what the same roll pays on the chest.

The full picture — 5 tiers × 3 zones

06

Read the number on screen

In game, the damage points and multiplier float up off the enemy and are gone in a split second (turn them on in the game's display settings if you don't see them). Learn to give every floating number the same furniture in your head — pips underneath, hitbox badge beside it — and any number decodes instantly. Review these examples between dungeons, not mid-fight. They use your calculator inputs and specific perk patterns, so the arithmetic is exact.

1 · Count the filled pipsThat's the tier — how many perks procced on this hit. The diamond is always Perk 1.
2 · Check the badge×3 head, ×2 chest, ×3 legs. The badge tells you how much of the number is aim, not luck.
3 · Do the one divisionNumber ÷ badge = your perked base. If it matches base damage, nothing procced — a plain hit, not a weak one.

Technical spec — for the dev team

How this example model is structured, so the production build can lift the model wholesale and replace only the shell.

Architecture: pure model, dumb UI

The single most important design decision: the damage model is pure functions with no UI, no rendering, and no game-engine dependencies. The UI (§01–§07) only ever calls the model and draws what it returns. That separation is what makes the model portable across stacks and testable without a headset.

// Core model — the whole system in five functions (JS shown; ports 1:1)
patternProbability(bits)  // product of p or (1-p) per perk
damageFor(base, bits, zoneMult)
  = base * zoneMult * (1 + Σ bonus[i] for each procced perk i)
tierStats()               // group 16 patterns by popcount → 5 tiers,
                          // probability-weighted avg damage + min/max
expectedDamage(base, zoneMult)
  = base * zoneMult * (1 + Σ procChance[i] * bonus[i])
rollPerks(rng)            // simulator: rng() < procChance[i] per perk

Extension points

  • New enemy: add one config entry (id, name, hitbox zones + multipliers); the matrix, tiers and legend regenerate from config. Its dummy-window art drops into the same record's layered stage slots — layers.backgroundImage (scene, cover), layers.mobImage (the enemy cutout, contain, rendered behind the zone overlay) and layers.foregroundImage — so per-enemy photography or artwork slots in without restructuring the stage.
  • New weapon type: add its base damage and per-column perk names/bonus magnitudes to config. Proc chances stay config too, in case a future patch retunes them.
  • Stacking rule: if verification (§10) shows bonuses stack multiplicatively rather than additively, only damageFor() changes: base × zone × Π(1 + bonus[i]). Everything downstream (tiers, matrix, expected value formula) must be updated in the same pass — expected damage has its own closed form under multiplication.
  • VR companion surface: keep it a second-screen web app (phone/tablet). Do not design in-headset interactions for this companion; in-game, the floating numbers themselves are the UI.
09

Installation & handoff guide

For the succeeding dev team picking this model up. No backend, no build step, no accounts — by design.

Run the example (2 minutes)

  1. Quickest: open index.html directly in any modern browser — desktop, phone, or tablet. Everything (model, config, UI) is in that one self-contained file.
  2. Served (recommended for phone testing): from the artifact folder run python3 -m http.server 8000 (or any static file host), then open the machine's address on the phone/tablet that will act as the second screen.
  3. Check it works: pick the Head zone in §03 — the calculator, matrix highlight and simulator should all follow; roll 100 shots in §07 and the tier tallies should land near the theory column.

Requirements: none beyond a browser. No server, database, network calls, or dependencies to install. State is intentionally not persisted — refresh resets the demo.

Lift the model into your stack

The model is engine-agnostic arithmetic over a config object. Port the five functions in §08 and the JSON config; leave this demo's HTML/CSS behind.

Verification checklist (run before shipping any port)

  • Tier probabilities sum to 100% (0.1886592 + 0.3921152 + 0.3028992 + 0.1032192 + 0.0131072 = 1.0).
  • Pattern enumeration yields exactly 16 patterns; tier × zone yields 48 outcomes / 15 cells.
  • Expected perks per hit = 1.36 (0.40 + 0.32 + 0.32 + 0.32).
  • Golden damage case (example config, base 100): Perk 1 + Perk 3 procced, Chest ×2 → 300. All four procced, Head ×3 → 570. Nothing procced, Legs ×3 → 300.
  • Simulator convergence: 10,000+ rolls should land within ~1 percentage point of the theory column per tier.
  • Config diff review on every game patch: proc chances, bonus magnitudes, and hitbox tables re-verified against the live game before republishing values.

10

Open questions — to verify against the live game

Nothing in this section is guessed at in the model. Each item blocks a specific production decision, noted beside it.

  • Exact perk bonus magnitudes — what does each perk column actually add, per weapon type? Blocks: replacing the example +30/+20/+20/+20% config values.
  • Additive or multiplicative stacking? — do procced bonuses add together before multiplying (this model's assumption), or compound perk-by-perk? Blocks: final damageFor() and the expected-damage formula (§08 extension point).
  • Perk names per weapon type — the real names for each column on each weapon type, to replace the generic Perk 1–4 labels in config and UI.
  • Hitbox tables for other enemies — zone layouts and multipliers beyond the Megamage's Head ×3 / Chest ×2 / Legs ×3, so the roster can be added as config. Every unknown zone in §03 already carries its exact question in this form.
  • Rounding of displayed damage — does the game floor, round, or truncate the floating damage points? Blocks: exact "read the number" decoding in §06 — a rounded display can sit 1 point off the model's exact output.
  • What the floating display actually shows — with the damage display toggled on, does the rising text show the final damage only, the multiplier separately, or both combined? Blocks: how literally the pip + badge reading system maps onto the in-game presentation.
  • Independence & re-roll timing — confirm each perk rolls independently per hit in the current version (this model's core assumption), and whether any weapon or effect re-rolls, guarantees, or suppresses a proc.
  • Exo suit stats — no exo-suit system exists in the game's public data, so §14 ships as placeholder inputs (damage dealt %, flat damage, perk amplification). Blocks: replacing the placeholders with the real suit's stats — or removing the layer if the shipped game has none.

Game data — weapons reference

Researched weapon data for Dungeons of Eternity (Othergate), organised the way it would live in the code base at resources/game-data/ — in this single-file demo it is this section. Compiled from public sources on 2026-10-20; the latest major update covered is Tomb Extraction, 21 Sep 2026. The game launched on Meta Quest 5 Oct 2023 ($29.99) and on SteamVR 11 Sep 2025 (app 3189340, $29.99, cross-play). Confidence overall: weapon classes, tiers, rarity and the update timeline — high (official patch notes and the community wiki agree). Perk magnitudes — medium (one community wiki table, partly corroborated by official perk names). Exact damage numbers and drop rates — low / absent: they are not published (see “Not publicly documented” below — that is a hard finding, not an omission).

How to read the source tags

Every value below carries the kind of source it came from. [O] Official Othergate update notes or Steam news for app 3189340. [C] Community the Forsaken Planet community wiki (the wiki the Fandom wiki itself points to as most up-to-date) or detailed Steam community reviews. [P] Press VR press (UploadVR, Mixed News, GamingTrend). Full source list with links at the end of this section. Where sources disagree or a value rests on a single report, the hedge is printed with the value — it is part of the data.

Important finding — the “4 perk columns” premise is not corroborated. No public source found describes weapons as having four perk columns or any fixed perk-slot count, and no source states how many perks a normal drop carries or how slots are filled. What is documented: perks roll on Unique / Rare / Legendary weapons from class-specific pools (table below); the Fabricator has an in-game perk information browser (added Dec 2023) [O]; a community Gear Drop Calculator exists “to figure out how likely a weapon will appear with a specific set of perks”, but its underlying probabilities were not retrievable [C]; and Mythic weapons let the player choose two perks [C]. The 4-column model in §01–§10 therefore remains exactly what §08 says it is — supplied example data for the model — not a researched game fact.

How weapons are actually obtained

  • You do not pick up finished weapons in a dungeon in the classic loop. Loot chests drop Weapon Modules (blueprints); you fabricate / craft the weapon at the Fabricator in your player room using the module. [C] wiki New Players Guide; corroborated by [P] GamingTrend (“loot… shown at the end of the dungeon as modules/designs”) and [O] patch notes repeatedly referencing the Fabricator and “newest weapon modules (blueprints)”.
  • Starting loadout: Sword (left hip), Throwing Axe (right hip), Bow (back). [C] [P]
  • Loadout = 3 slots: Left Hip, Right Hip, Back. Sidearms (one-handed: swords, daggers, maces, hammers, axes) go on hips; two-handed gear (bow, staff, 2-hand sword, shield) goes on the back. [C] wiki + Fandom wiki.
  • Vendors (from 11 Sep 2025, “Mythic Promotion”): an Armorer now sells / “smiths” hard-to-find weapons in the Outpost; a weapons vendor sells items (e.g. the Sickle at a discount, random availability). [O] Othergate updates, Sep 11 2025 / Oct 25 2025.
  • Cosmetic chest fallback: if you have collected all cosmetics, cosmetic chests give a random weapon drop instead. [O] Jan 2024.
  • Rating reward: a free special weapon is given in the loadouts menu for rating the game. [O] Jul 2024.

Levels, tiers & rarity

  • Weapon Tiers 1–7. “There are seven weapon tiers, and each tier for a weapon is differentiated by its shape (it's 3D model)” — tier is expressed in the weapon's model / materials, not a “+N upgrade” number. Tier 7 styles exist for all weapon types (added May 2024 with the level 50+ unlock tier). [C] [O] May 2 2024; materials pass “to better represent the tiers and class of weapons”, Oct 2023.
  • Player level (max 60; raised from 50 on 2 May 2024) determines three linked things: your recommended dungeon difficulty tier, the weapon tier you loot, and which rarities can appear. [C] [O]
  • Playing above your recommended difficulty: weapon loot is at most +1 tier above your player's tier; from 31 Jan 2025 this is formalised as the Difficulty Bonus — bonus XP/Gold and +1 Tier weapon loot when playing above your recommended tier. [C] [O] Jan 31 2025.
  • Rarity ladder: Common (most basic, no enchantments) < Unique (recognisable by a blue glow) < Rare < Legendary (strongest). Unique / Rare / Legendary weapons can carry elemental features — Fire, Ice, or Poison — and perks. [C] Rarity colour coding beyond Unique's blue glow and Auric's gold name colour is not documented in retrieved sources — do not assume standard grey/blue/purple/orange conventions.
  • Upgrades: no separate per-weapon “upgrade level / +1…+10” system is documented in any source found. Progression is: find a higher-tier / higher-rarity module → fabricate it. Fabricator cost per weapon type was “rebalanced” (May 2024), and Auric/Spectral have their own damage-cost tables [O] — gold crafting cost scales with the weapon, but the tables themselves are not published.

Damage model & scaling — what is actually known

  • The only published damage-scaling rule [C]: “Any weapon's damage for any Weapon Module you find will be between ABOUT 1x and 2x what your level is at the time of the drop — this scales to level 60. Scale factor dependent on weapon type, like crossbows are closer to 1x, Long Swords are closer to 2x.” An older revision phrases the low end as “for the first thirty levels or so the weapons you find will have about the same damage as your level number.” → Practical model: dropped weapon's damage stat ≈ player level × (1.0–2.0), class-dependent.
  • Swing / throw force modifies damage: damage dealt = weapon's damage number ± strength of your swing/throw. The tutorial does not quantify this. [C] [P] GamingTrend (“swinging harder does more damage”).
  • The wiki states each weapon type “has a different damage chart” and links a Combat Simulator and a Gear Drop Calculator; the charts/tools' data were not retrievable in this research. No per-class base-damage table is published in text form anywhere found.
  • Class damage ranking (qualitative): after the 2 May 2024 rebalance, “Sword damage was adjusted and has the highest damage now” [O]; press on the same update says two-handed swords “deal the highest damage of all weapon types” [P] Mixed News. Dagger damage was increased in the first patch (30 Oct 2023, no number given) [O]. Minor hammer/axe damage tweaks May 2024 [O].

Documented multipliers

  • Criticals perk: 20–32% chance to crit for 300% damage. [C]
  • Spectral Echo: delayed second hit at double damage. [O]
  • First-strike bonus (Crypts, Sep 2026): an unaware enemy takes 3x damage on the first hit. [O]
  • Crossbow Reload trade-off: each Reload Perk tier reduces damage per bolt by 7.5% — the only official perk-magnitude number found. [O] Jan 2024.
  • Bombs: damage ×4 (May 29 2024); AoE damage ~×2 again (Jul 23 2024). [O]

Swords — one-handed

High · perk nos. Medium

The default melee class; varied blade lengths; “great melee” weapon. Starting weapon (left hip). Sidearm slot (hip). Standard 7 tiers / 4 rarities.

Damage
Wiki (pre-May-2024 wording): “Swords do highest damage.” Officially, May 2024: “Sword damage was adjusted and has the highest damage now.” Module damage follows the ~1–2× player-level rule.
Perk pool
Vampire (20–32% chance to heal 25% of your health), Stab Damage (+50% damage), plus all-class perks. A Throwable perk exists for swords (“Sword Spire throwable sword perk” fixed May 2024).
Niche
Sharp weapon — very effective vs Zombies; can stick into enemies when stabbed/thrown. Unlike true throwing weapons, a plain sword has no soft target tracking when thrown unless it has the Throwable perk.

Sources: Forsaken Planet wiki; Othergate updates May 2 2024; Steam top review. [C] [O]

Two-Handed Swords / Longswords

High

Added 2 May 2024 (“Longswords & Traps”). Two-handed sword, holstered on the back, with “special random perks” of its own. Top-end melee. Gained Tier 7 styles with all types in the same update; max player level rose 50→60 and Tier 7 “Nightmare” difficulty launched alongside.

Damage
“Closer to 2x” player level on the wiki's scaling chart — the top of the damage-scale band; press: highest damage of all weapon types.
Perk pool
Unblockable (prevents parries), Vampire (20–30% chance to heal 25% HP — note: wiki lists 20–30% here vs 20–32% for 1H swords), Knock-back Distance (increases distance enemies are thrown when pushed), plus all-class perks.
Niche
Two-handed grip mechanics (improved Oct 2024, incl. reverse-grip poses); a two-handed swing knocks enemies back like a shield bash; longsword has a bash attack (bash fixes Dec 2024); longsword can block skeleton/boss attacks (fix Dec 2025 implies blocking is a feature).

Sources: Othergate updates May 2 2024 / Oct 17 2024 / Dec 2025; Mixed News; Forsaken wiki. [O] [C] [P]

Axes — incl. Throwing Axes

High

Reliable melee that is also a true thrown weapon — “great for mid-range attacks”; starting weapon is a Throwing Axe (right hip). Standard tiers. Drops: chest modules; seasonal Candy Cane Axes (Frostbound, Dec 2023).

Damage
Minor damage tweaks May 2024; follows ~1–2× level scaling.
Perk pool
Throw Damage (+5–35% throwing damage), Explosions (20–32% chance to explode for 200% damage), plus all-class perks.
Niche
Thrown axes have soft target tracking and magnetic recall — throw it, then call it back with the magnetic/force grab; it can hit enemies on the return path. Axe throw targeting ballistics repeatedly tuned. Known quirk fixed Oct 2024: lower-tier axes with multiple stab points did excessive damage (multi-stab-point contact multiplies hits).

Sources: Forsaken wiki; UploadVR reviews; Othergate updates. [C] [P] [O]

Maces / Hammers / Clubs — blunt class

High identity · Medium perks

One class with three model families (maces, hammers, clubs) sharing melee + throw physics. Hammers: “hard-hitting melee… more effective on armored hostiles, can be thrown but for a limited distance.” Standard tiers. Drops: chest modules; Armorer.

Damage
Minor hammer damage tweaks May 2024; blunt weapons are “more throwable and effective on skeleton type enemies”.
Perk pool
Listed under “Hammers”: Slowing (20–32% chance to slow enemy), Area Damage (20–32% chance to explode for 200% damage), plus all-class perks. Mace-specific pools are not separately published.
Niche
True thrown weapon — soft target tracking; blunt = anti-skeleton / anti-armor niche. Mythic hammer area-damage fixes (Oct 2025) confirm a Mythic hammer variant exists.

Sources: Forsaken wiki; Steam review; Othergate. [C] [O]

Daggers

High

Close-quarters stabbing weapon; “the most throwable” weapon class. Standard tiers. Drops: chest modules; vendors.

Damage
Dagger damage increased in the first patch (30 Oct 2023) — no number published; improved dagger stabbing kills Dec 2023.
Perk pool
Vampire (20–32% chance to heal 25% HP), Poison (20–32% chance to poison enemy), plus all-class perks.
Niche
Thrown at high velocity with quick return; soft target tracking when thrown. Stealth synergy is systemic rather than dagger-specific in sources: the Crypts' first-strike 3x damage on unaware enemies and the Skull Dagger (Crypt weapons, below) is the stealth dagger. A “Mythic Dagger exploit” fix (Sep 2026) confirms a Mythic dagger exists.

Sources: Forsaken wiki; Othergate updates. [C] [O]

Spears

High identity · Low perk pool

Added 17 Oct 2024 (“Halloween Sandbox”). Reach melee + ranged hybrid: “Stab enemies or attack them from distance by throwing it.” Standard tiers (added with full tier range). Drops: chest modules; vendors.

Damage
Follows general scaling; no spear-specific numbers published. A Mythic spear has an explosion effect (fix note, Oct 2025).
Perk pool
Not separately published in the wiki table retrieved (spears postdate the table's core). Only all-class perks can be assumed — flagged as undocumented, not assumed in data.
Niche
True thrown weapon with soft target tracking; stab-capable (spears fixed to stab jumping/attacking enemies, Oct 2024).

Sources: Othergate Oct 17 2024; Steam review. [O] [C]

Bows

High

Two-handed ranged weapon, back slot; starting weapon (back). “Great ranged weapon… effective on all hostiles.” Standard tiers. Drops: chest modules. Variant: Gravelight Bow (Crypt weapon, below).

Damage
Follows ~1–2× level scaling; no bow-specific figure published.
Perk pool
Shot Distance (+10–70% shooting range), Slowing (20–32% chance to slow), plus all-class perks.
Niche
Arrows are unlimited (draw from quiver on your back); physical draw-and-nock mechanics (haptics on nock; the “semi-auto bow” exploit — arrow must leave the quiver area before re-nock — was fixed Oct 2024). Bows knock back enemies on melee contact but do no melee damage (exploit fix, Dec 2023: “They still knock back enemies though”).

Sources: Forsaken wiki; Othergate; UploadVR. [C] [O] [P]

Crossbows

High

One-handed ranged weapon; load a bolt by pulling the string back with your off-hand. Two families: single-shot (higher damage per shot) vs multi-loading (several shots per reload, less damage per shot). Standard tiers. Drops: chest modules.

Damage
Sits at the low end of the scaling band — “closer to 1x” player level. Official balance: each Reload Perk tier = −7.5% damage per bolt/shot (Jan 2024).
Perk pool
Slowing (20–32% chance to slow), Reload (+1–7 extra shots per reload), plus all-class perks.
Niche
One-handed operation leaves the other hand free (shield/weapon pairing); aiming-assist / head-tilt mechanic improved Jul 2024; multi-load + Ice elemental is a popular community build.

Sources: Forsaken wiki; Othergate Jan 2024; Steam review. [C] [O]

Magic Staffs / Staves

High mechanics · Low roster

Not a generated class like the others: the wiki states there are eight individual magic staffs, each a distinct weapon with its own ability. Back slot. Staffs exist across tiers (a “melee staff fabricating as Fireball Staff” bug implies staff modules roll types); details not published. Drops: chest modules → Fabricator; seasonal staffs during events.

Named
Fireball Staff (projectile fireballs; fireballs-per-gem increased Jan 2024), Ice Staff (freezes enemies — bosses can no longer be frozen but still take ice damage, Jan 2024), Healing/Health Staff (heals allies, removes freeze/poison from allies, resurrects fallen allies at distance; its beam damaged enemies May 2024 → beam damage removed 29 May 2024, melee unchanged), Chrono Staff (slows enemies), Shockwave Staff (named in May 2024 fix notes), Melee Staff (the basic staff, renamed from “basic staff” Oct 2023 to clarify it is melee). Seasonal: Santa's Fireball Staff (Dec 2023). Mode weapons: Crypt Keeper's Staff, Necromancer Staff (Crypt weapons, below). ⚠ That is 6 regular staffs named; the wiki's count of 8 could not be fully enumerated from retrieved sources.
Damage
No staff damage numbers published anywhere found.
Perk pool
Not published as a pool; staffs are defined by their innate ability rather than rolled perks in sources found.
Niche
Power Gem / magic crystal charges: staffs have limited casts; when depleted you insert another Power Gem. A Steam reviewer reports you can carry max 3 crystals and a depleted staff is “a useless stick” — single detailed review, treat as unconfirmed. Necromancer staff (Crypt) refines this: consumes a gem per cast, gem returns when no charmed enemies remain.

Sources: Forsaken wiki; Othergate updates; Steam review. [C] [O]

Shields

High

Defensive back-slot item: “protect the wielder against all hostile attacks and projectiles.” Standard tiers. Drops: chest modules.

Damage
Shields are an attack tool via bash/shove; no damage numbers published. A Mythic shield exists (“not bouncing back from breakables” fix, Sep 2026).

Thrown weapons & bombs

Medium-High

Cross-cutting category. Any weapon can be thrown, but a true “thrown weapon” has soft target tracking that assists aim mid-flight.

Tracking
Tracking classes: daggers, axes, maces, spears. Swords track only with the Throwable perk. Thrown weapons are recalled via magnetic/force grab.
Bombs
Bomb damage ×4 (May 2024), AoE ~×2 (Jul 2024). Seasonal Pumpkin Cluster Bomb (Oct 2025, in dungeons + cosmetics vendor) became a permanent “Cluster Bomb” weapon type in Jan 2026.
Sickle
25 Oct 2025, Stormgrave: new weapon, found in chests (rare) or at the weapons vendor at a discount, availability random (check after each run); seasonal availability originally ended 10 Nov 2025. Class/perk data not published.

Sources: Steam review (thrown definition); Othergate updates. [C] [O] [P]

The five Crypt weapons — Tomb Extraction, 21 Sep 2026

Official notes [O] unless marked [P]. Confidence: High (official notes verbatim; no damage numbers published for any of them).

Crypt Keeper's Staff

Fires a guided light orb that ignites dark lights and damages enemies; a beam ignites nearby lights; can charge wall torches at the cost of its own light; stays lit in the back holster. (Steam news adds: pull the trigger again to detonate the orb.)

Necromancer Staff

3-second beam charms an enemy; charmed enemy is healed to 3x HP, follows you and fights for you; has stab points for extra damage; consumes a Power Gem per cast, returned when no charmed enemies remain.

Gravelight Bow

Crystal arrows ignite what they hit; glows when enemies are near; can blast enemies away.

Crypt Hammer / “Tomb Breaker”

Bashes skeletons into walls where they shatter; one-hit kill on ordinary skeletons (not guards); follows the player when left behind; smashes sealed tombs; very useful vs armored enemies.

Skull Dagger

Glows blue near skeletons; applies slow kinetics when thrown; breaks when used on a guard; [P] found throughout the crypts and used for stealth kills.

Not publicly documented — explicit gaps

These are open questions, stated plainly. Nothing here is filled in by guessing, in this section or anywhere else on the page.

  1. Drop rates: No percentage drop rates, rarity probabilities, loot-table weights, or per-source weapon odds are published anywhere found (official or community). Chest contents are described only qualitatively (“likely” / “always” for Tier 2/3 modules).
  2. Perk roll chances & slot structure: No source describes “4 perk columns” or any fixed perk-slot count for normal drops, nor the probability of rolling a specific perk. (A community Gear Drop Calculator exists on the wiki but its data was not retrievable via the web index; the in-game Fabricator perk browser is the authoritative in-game reference.) Mythic weapons are the exception: two player-chosen perks [C].
  3. Per-class damage tables: No base damage values or per-level damage tables per class are published in text form. Only the community rule of thumb (module damage ≈ 1–2× player level at drop, class-dependent; crossbows ~1×, Long Swords ~2×) exists. The wiki references per-type “damage charts”/a scatter plot and a Combat Simulator whose data could not be retrieved.
  4. Swing/throw force formula: Damage is modified by swing/throw strength, but the formula/multiplier is not quantified in any retrieved source (the in-game tutorial explicitly doesn't quantify it [C]).
  5. Staff roster: Wiki says 8 individual magic staffs; only 6 regular ones are named across all sources found (Fireball, Ice, Healing, Chrono, Shockwave, Melee). The remaining staff(s) could not be identified from public text sources.
  6. Spears & post-2024 classes' perk pools: The wiki perk table predates/omits spears, sickles, and Crypt/Auric/Spectral-specific pools (beyond their guaranteed perks). Not published.
  7. Stamina / attack speed / base crit / range stats per class: No stamina system or per-class attack-speed/crit stats are documented in any source found. The only range number is the Bow Shot Distance perk (+10–70%).
  8. Auric/Spectral/Mythic numbers: Their “damage-cost tables”, six-tier material names/colours (beyond Auric = gold), Mythic charged-move damage/cooldown values, and ring perk lists are asserted to exist [O] but are not published.
  9. Rarity colour coding beyond Unique's blue glow and Auric's gold name colour is not documented in retrieved sources (do not assume standard grey/blue/purple/orange conventions).
  10. Rare-unlock level discrepancy: community guide internally inconsistent (Rare at L10 in one list, L12 in another/older revision).
